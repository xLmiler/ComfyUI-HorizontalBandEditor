# ComfyUI-HorizontalBandEditor

ComfyUI 横向截断 / 文字面板编辑器。

## 主要功能
- 使用 ComfyUI **加载图像** 节点作为输入。
- 在预览中拖拽横向选区，宽度始终覆盖整张图。
- 可保存**多个截面**。
- 删除模式：一次删除全部保存截面，并按原顺序拼接剩余内容。
- 文字面板模式：每个截面都替换为同一文字面板；文字超高时自动扩展。
- 纯色或透明背景。
- 默认简中黑体，支持字体路径、字号、颜色、内边距、行距与对齐。
- 输出 RGB、MASK、RGBA。

## UI 兼容
插件会读取 ComfyUI 系统设置：

`Comfy.VueNodes.Enabled`

- 系统关闭“节点 2.0”时：使用经典节点布局。
- 系统开启“节点 2.0”时：使用 Nodes 2.0 布局。
- 节点自身不再提供 UI 模式开关。

增强界面使用固定高度滚动区，因此无需把整个节点拉得很高才能看全参数。若前端 JS 未加载，Python 原生控件仍会作为回退显示。

## 多截面操作
1. 连接“加载图像”的 IMAGE 到“输入图像”。
2. 点击“从输入图像同步预览”。
3. 在预览上拖拽选择当前截面。
4. 点击“添加当前截面”。
5. 重复选择并添加其它截面。
6. 点击已保存截面可重新编辑，再使用“更新选中截面”。
7. 执行工作流。

重叠或相邻的截面会自动合并，避免重复删除。

## 安装
解压到：

```text
ComfyUI/custom_nodes/ComfyUI-HorizontalBandEditor/
```

重启 ComfyUI，并在浏览器中按 `Ctrl + F5`。
