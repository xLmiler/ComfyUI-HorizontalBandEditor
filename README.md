# ComfyUI-HorizontalBandEditor

用于在 ComfyUI 中对图像进行横向截断、批量截面删除以及文字面板替换。

## v1.5 UI 设计

本版本恢复到 ComfyUI 原生节点设置模式：

- 参数全部使用 ComfyUI 自带 widget。
- 用户在 ComfyUI 系统设置中开启或关闭“节点 2.0”即可，插件本身不会再选择 UI 模式。
- 前端脚本仅负责动态隐藏当前无关参数。
- 可视化编辑预览只保留一份，并固定在所有设置的最下方。
- 拉高整个节点时，底部预览会跟随增加高度。

## 使用

1. 添加 ComfyUI **加载图像** 节点。
2. 将其 `IMAGE` 输出连接到本节点的 **输入图像**。
3. 设置 **截面数量**。最多支持 12 个截面，以 A-L 标记。
4. 使用 **编辑截面** 切换当前截面。
5. 在底部预览图中拖拽设置当前截面。
6. 点击已有截面可以直接切换；拖动边缘调整高度；拖动截面内部可整体移动。
7. 关闭 **启用文字面板** 时，所有截面都会被删除，上下剩余图像按顺序拼接。
8. 开启 **启用文字面板** 时，每个截面会被替换成同一套文字面板；文字高度不足时输出会自动扩高。

## 动态参数

- `启用文字面板 = 关闭`：隐藏面板背景、颜色、文字、字体、字号、边距与对齐参数。
- `启用文字面板 = 开启`：显示文字面板参数。
- `面板背景 = 透明`：自动隐藏背景颜色。
- 切换 `编辑截面`：只显示当前截面的上下边界参数，其余截面坐标保持保存但隐藏。

## 安装

解压到：

```text
ComfyUI/custom_nodes/ComfyUI-HorizontalBandEditor/
```

重启 ComfyUI 后建议浏览器执行一次 `Ctrl + F5`。
