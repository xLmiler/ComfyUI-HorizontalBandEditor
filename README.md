# ComfyUI-HorizontalBandEditor

一个用于 **ComfyUI 横向区域编辑** 与 **表图 / 里图动画 WebP 合成** 的自定义节点插件。

---

## 当前节点

当前插件保留以下核心节点：

| 节点 | 分类 | 用途 |
|---|---|---|
| `横向截断面板编辑器` | 图像/编辑 | 删除多个横向截面并自动拼接，或用文字面板替换这些横向截面 |
| `表里图合并编辑器` | 图像/保存 | 将表图与里图合成为单个动画 WebP，并写入 ComfyUI 兼容的工作流元数据 |
| `读取WebP里图` | 图像/加载 | 读取本插件生成的表里图 WebP，并直接输出里图 IMAGE / 图片组 |

---

## 主要能力

- 最多 12 个横向截面同时编辑
- 文字面板替换横向区域
- 背景颜色 / 文字颜色支持调色盘和十六进制输入
- 表图占位颜色支持调色盘和十六进制输入
- 表图 + 里图合成为单个动画 WebP
- 直接拖回 ComfyUI 画布恢复 workflow
- GIF 可继承原始每帧时长
- 支持自定义帧时长、播放速度倍率、动画抽帧步长
- 输出 WebP 默认 **无限循环播放**

---

## 表里图合并编辑器 - 动画行为

当里图来自 GIF 或多帧图片组时，动画最终会按以下逻辑处理：

- `表图连续帧数`：决定开头有多少帧属于表图
- `表图停留时长(ms)`：决定动画开始前，表图首帧停留多久
- `继承GIF原始帧时长`：尽量使用源 GIF 的每帧 duration
- `自定义帧时长(ms)`：用于普通图片组或不继承 GIF 时长时
- `播放速度倍率`：整体加速 / 减速里图动画
- `动画抽帧步长`：按步长抽帧以降低体积
- `WebP质量` / `无损`：控制输出大小和压缩质量

### 当前默认行为

- 表图首帧会先停留一段时间（默认 1200ms）
- 然后开始播放里图动画
- 动画播放完后会重新从头循环

如果你想让封面停留更久，可以把：

```text
表图停留时长(ms)
```

调高，例如：

- `1000` = 1 秒
- `3000` = 3 秒
- `5000` = 5 秒

---

## 推荐 GIF 参数

如果 GIF 帧数较多、体积较大，建议先尝试：

```text
继承GIF原始帧时长 = 开
播放速度倍率 = 1.0
动画抽帧步长 = 2
WebP质量 = 75~82
无损 = 关
表图停留时长(ms) = 1000~2000
```

这样通常既能保留动画节奏，又能明显减小体积。

## 安装

放到：

```text
ComfyUI/custom_nodes/ComfyUI-HorizontalBandEditor/
```

安装后：

1. 重启 ComfyUI
2. 浏览器按一次：

```text
Ctrl + F5
```
